# 토비의 스프링 부트 - 이해와 원리 강의 가이드

## 강의 정보

| 항목 | 내용 |
|---|---|
| 강사 | 토비 |
| 난이도 | 초급 |
| 총 강의 시간 | 11시간 7분 |
| 수업 수 | 68개 (섹션 12개) |
| 링크 | https://www.inflearn.com/course/토비-스프링부트-이해와원리 |

## 목적

스프링 부트의 핵심 기능을 직접 만들어 보며 동작 원리를 이해하고, 스프링 부트를 제대로 학습·활용하는 방법을 익힌다.

## 무엇을 배우나

독립 실행형 서블릿·스프링 애플리케이션, DI와 테스트, 자동 구성, 조건부 자동 구성(@Conditional), 외부 설정, Spring JDBC 자동 구성 개발, 스프링 부트 자세히 살펴보기를 다룬다.

### 인프런 소개 기준 학습 내용

- 스프링 부트의 동작 원리
- 스프링 부트가 제공하는 기술과 구성을 파악하고 활용하는 방법
- 스프링 프레임워크의 핵심 기술과 활용법
- 나만의 스프링 부트 모듈을 만드는 방법

## 이런 분께 추천

- 스프링 부트를 더 잘 이해하고 자유롭게 활용하고 싶은 분
- 스프링 부트를 사용하고 있지만 스프링에 대해서는 잘 모르겠다고 느끼시는 분
- 스프링 부트를 효과적으로 학습하고 싶은 분
- 나만의 스프링 부트 모듈을 만들어 사용하고 싶은 분

## 선수 지식

- 자바 언어(자바 8+)

## 관련 도서

- 섹션 5. 독립 실행형 스프링 애플리케이션 → 토비의 스프링 3.1 Vol.2 1장 IoC 컨테이너와 DI (추가 연관)
- 섹션 6. DI와 테스트, 디자인 패턴 → 토비의 스프링 3.1 Vol.1 1장 오브젝트와 의존관계 (추가 연관)
- 섹션 6. DI와 테스트, 디자인 패턴 → 토비의 스프링 3.1 Vol.1 2장 테스트 (추가 연관)
- 섹션 7. 자동 구성 기반 애플리케이션 → 토비의 스프링 3.1 Vol.2 7장 스프링의 기타 기술과 효과적인 학습 방법 (빈 확장·설정 모듈 부분)
- 섹션 8. 조건부 자동 구성 → 토비의 스프링 3.1 Vol.2 7장 스프링의 기타 기술과 효과적인 학습 방법 (추가 연관)
- 섹션 9. 외부 설정을 이용한 자동 구성 → 토비의 스프링 3.1 Vol.2 1장 IoC 컨테이너와 DI (추가 연관)
- 섹션 10. Spring JDBC 자동 구성 개발 → 토비의 스프링 3.1 Vol.1 3장 템플릿 (추가 연관)
- 섹션 10. Spring JDBC 자동 구성 개발 → 토비의 스프링 3.1 Vol.2 2장 데이터 액세스 기술 (추가 연관)
