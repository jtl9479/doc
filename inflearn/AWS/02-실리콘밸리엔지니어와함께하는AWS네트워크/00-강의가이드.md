## 목적

AWS 네트워크 완벽 마스터! VPC, 서브넷, 라우팅, 보안까지 실전 중심으로 배우고 안전하고 확장 가능한 클라우드 네트워크 아키텍처를 설계하세요. 실무 엔지니어라면 반드시 알아야 할 핵심 스킬을 단기간에 완성합니다!

## 무엇을 배우나

- AWS VPC: 서브넷, 라우팅 테이블, 게이트웨이 완벽 이해
- 네트워크 보안: Security Group, NACL 활용법
- 트러블슈팅 & 최적화: 네트워크 성능 모니터링 및 비용 절감 전략

## 이런 분께 추천

- 라우드 네트워크를 처음 배우는 개발자 & 엔지니어
- AWS 기반 인프라를 설계·운영하는 DevOps 엔지니어
- 클라우드 아키텍처를 설계하는 솔루션 아키텍트
- 네트워크 엔지니어
