# 실전! 스프링부트 상품-주문 API 개발로 알아보는 TDD 강의 가이드

## 강의 정보

| 항목 | 내용 |
|---|---|
| 강사 | 이중석 |
| 난이도 | 초급 |
| 총 강의 시간 | 2시간 43분 |
| 수업 수 | 23개 (섹션 8개) |
| 링크 | https://www.inflearn.com/course/스프링부트-실전-상품주문-tdd |

## 목적

상품·주문 API를 TDD로 만들며 테스트 주도적인 사고방식과 테스트 코드 작성법을 익힌다.

## 무엇을 배우나

상품 등록·조회·수정, 주문, 결제 API를 POJO 테스트 → 스프링부트 테스트 → API 테스트 순서로 전환하며 개발하고, 패키지 구조를 정리한다.

### 인프런 소개 기준 학습 내용

- 테스트 코드 작성 방법
- 테스트 주도적인 사고방식

## 이런 분께 추천

- TDD가 궁금한 개발자
- 테스트 코드부터 작성하기 어려운 개발자
- 실무에서도 TDD를 하고싶은 개발자

## 선수 지식

- 자바 언어
- 스프링부트
- Junit5

## 섹션 구성

1. 소개
2. 상품 등록 API 개발
3. 상품 조회 API 개발
4. 상품 수정 API 개발
5. 상품 주문 API 개발
6. 주문 결제 API 개발
7. 상세 패키지 구조 만들기
8. 리뷰반영
