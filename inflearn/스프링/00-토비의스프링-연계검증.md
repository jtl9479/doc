# 토비의 스프링 연계 검증 보고서

강의 섹션 파일의 "관련 도서"에 적힌 **토비의 스프링 3.1** 연결 71개(엑셀 연계표 11개 + 추가 연관 60개)를 실제 영상 제목과 책의 절·소절 목차로 대조한 결과입니다.

- 기준 목차: 토비의 스프링 3.1 Vol.1·Vol.2 (예스24 상품 페이지 목차, 2026-11-05 확인)
- 영상 기준: 인프런 공개 커리큘럼 수업 제목 (퀴즈 제외)
- 판정
  - **적합**: 영상 주제와 책 절이 직접 대응
  - **부분**: 일부 영상만 대응하거나 책은 같은 개념을 다른(옛) 기술로 설명
  - **약함**: 책 3.1 범위 밖의 기술이 대부분이라 대응이 거의 없음
  - **수정 필요**: 장 지정이 틀렸거나 더 맞는 장이 따로 있음
- 엑셀 연계표 연결은 "엑셀", 제가 추가한 연결은 "추가"로 구분했습니다.

### 엑셀 연계표와 다르게 본 부분

- **핵심 원리 기본편 03 ↔ Vol.1 1장 (엑셀: 매우 높음)**: 03은 순수 자바로 예제를 만드는 섹션이라 1.1 초난감 DAO 정도만 대응합니다. 1장의 핵심(1.2 관심사 분리 ~ 1.7 DI)은 **04. 객체 지향 원리 적용**과 훨씬 잘 맞습니다. → 03은 "부분", 04를 1장의 주 연결로 보는 것을 권장합니다.
- **토비의 스프링 부트 07 ↔ Vol.2 7장 (엑셀: 부분)**: 영상의 "빈 오브젝트의 역할과 구분", "인프라 빈 구성 정보의 분리", "동적인 자동 구성 정보 등록"이 Vol.2 1.5.1~1.5.2와 7.8(@Enable, ImportSelector)에 직접 대응합니다. → "적합"으로 올려도 됩니다.
