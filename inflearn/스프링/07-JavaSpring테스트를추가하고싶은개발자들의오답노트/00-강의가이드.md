## 목적

스프링 프로젝트에 테스트를 자연스럽게 넣는 방법과, 테스트하기 쉬운 구조로 설계를 바꾸는 방법을 익힌다.

## 무엇을 배우나

테스트 개념과 이론, 기존 프로젝트에 테스트 추가하기, 레이어드 아키텍처의 문제점, 의존성 역전과 Testability, Mockito 없이 테스트하기, 헥사고날 아키텍처로의 진화를 다룬다.

### 인프런 소개 기준 학습 내용

- Spring에 테스트를 넣는 방법
- 테스트에 필요한 개념
- 자연스러운 테스트를 하는 방법
- Mockito 없이 테스트하는 방법
- 의존성과 Testability
- 헥사고날 아키텍처(Hexagonal Architecture)와 설계

## 이런 분께 추천

- Spring에 테스트를 넣고 싶은 분
- Spring에 테스트를 어떻게 넣어야 할지 막막하신 분
- 내가 개발한 Spring 프로젝트가 올바른 설계 구조인지 헷갈리는 분
- 테스트를 넣어보려 했지만 실패했던 분
- H2 같은 테스트 DB가 없는 NoSQL에 테스트를 넣고 싶은 분

## 선수 지식

- Java 코드를 이해하실 수 있으신 분
- Spring 기본 (Controller / Service / Repository가 무엇인지 아시는 분)
- JPA를 사용해보신 분
