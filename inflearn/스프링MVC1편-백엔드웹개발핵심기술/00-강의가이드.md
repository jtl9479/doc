## 목적

## 무엇을 배우나

웹 서버·WAS·서블릿 기초, JSP와 MVC 패턴, MVC 프레임워크 직접 만들기, 스프링 MVC 구조(핸들러 매핑·어댑터·뷰 리졸버)와 기본 기능, 웹 페이지 만들기를 다룬다.
