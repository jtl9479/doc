## 목적

Kotlin 문법을 익히고 Kotlin으로 Spring Boot와 Spring Security 기반 로그인 페이지를 만들어 본다.

## 무엇을 배우나

Kotlin 기본 문법, Thymeleaf 웹 페이지, H2·JPA 기본 설정, Spring Security로 로그인 구현을 다룬다.

### 인프런 소개 기준 학습 내용

- Kotlin의 별난 문법
- kotlin으로 Spring Boot 시작하기
- Kotlin으로 만드는 Spring Security
- Spring Security로 만드는 로그인 페이지

## 이런 분께 추천

- Spring Security를 배우고자 하는 분
- Kotlin으로 Spring Boot 개발을 하려는 분
- Spring Boot를 배우고자 하는 분

## 선수 지식

- 자바 기본
- HTML, CSS 기본

## 섹션 구성

1. Kotlin 기본 문법
2. 프로그래밍을 배우는 방법
3. Thymeleaf 로 웹 페이지 만들기
4. 기본 jpa
5. 기본 Spring Security
