초보자를 위한 BigQuery(SQL) 입문 강의입니다. 데이터를 가공하는 방법이 궁금하신 분에게 추천합니다. 백엔드 개발 관점보다는 데이터 분석, 데이터 엔지니어링 관점의 SQL을 알려드립니다.

## 무엇을 배우나

- BigQuery
- SQL
- 데이터 분석
- 데이터 결과 검증
- 가독성 있는 쿼리를 작성하는 방법

- BigQuery를 처음 학습하는 분
- SQL 기본 개념을 익히고 싶으신 분
