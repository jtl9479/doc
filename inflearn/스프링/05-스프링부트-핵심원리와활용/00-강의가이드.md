# 스프링 부트 - 핵심 원리와 활용 강의 가이드

## 강의 정보

| 항목 | 내용 |
|---|---|
| 강사 | 김영한 |
| 난이도 | 초급 |
| 총 강의 시간 | 15시간 46분 |
| 수업 수 | 107개 (섹션 12개) |

## 목적

실무에 필요한 스프링 부트의 내부 동작 원리와 핵심 기능, 모니터링까지 한 번에 정리한다.

## 무엇을 배우나

웹 서버와 서블릿 컨테이너, 내장 톰캣, 스타터와 라이브러리 관리, 자동 구성, 외부 설정과 프로필, 액츄에이터, 마이크로미터·프로메테우스·그라파나, 모니터링 메트릭 활용을 배운다.

### 인프런 소개 기준 학습 내용

- 스프링 부트의 내부 동작 원리
- 스프링 부트 라이브러리 만들기
- 스프링 부트가 제공하는 핵심 기능 이해
- 스프링 부트를 활용한 모니터링

## 이런 분께 추천

- 스프링 부트를 깊이있게 이해하고 싶은 개발자
- 스프링 부트를 코드로 쉽게 이해하고 싶은 개발자
- 개발자 취업 준비생
- 실무에서 스프링 부트를 사용하지만 스프링 부트의 핵심 원리를 제대로 이해하고 사용하고 싶은 개발자

## 선수 지식

- 자바 언어
- 스프링 학습 경험
