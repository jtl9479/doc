# 예제로 배우는 스프링 입문 (개정판) 강의 가이드

## 강의 정보

| 항목 | 내용 |
|---|---|
| 강사 | 백기선 |
| 난이도 | 초급 |
| 총 강의 시간 | 2시간 26분 |
| 수업 수 | 13개 (섹션 5개) |
| 링크 | https://www.inflearn.com/course/spring_revised_edition |

## 목적

스프링 공식 예제 PetClinic 코드를 보며 스프링의 철학과 핵심 기능(IoC·AOP·PSA)을 빠르게 이해한다.

## 무엇을 배우나

PetClinic 프로젝트 살펴보기, 스프링 IoC와 컨테이너, 빈·의존성 주입, AOP와 프록시 패턴, PSA를 짧게 다룬다.

### 인프런 소개 기준 학습 내용

- 앞으로 더 깊이 스프링 프레임워크를 학습하는데 디딤돌이 될 지식을 학습할 수 있습니다.
- 스프링 프레임워크가 가진 철학을 엿볼 수 있습니다.
- 스프링 프레임워크의 핵심 기능에 대해 알 수 있습니다.

## 이런 분께 추천

- 스프링의 핵심 기능과 철학에 대해 빠르게 학습하고 싶은 개발자 또는 학생
- 스프링이 뭔지 궁금한 개발자 또는 학생
- 스프링을 처음 접하는 입문자

## 선수 지식

- 인텔리J 또는 이클립스 (STS)
- 메이븐 또는 그래들
- 자바

## 관련 도서

- 섹션 3. 스프링 IoC → 토비의 스프링 3.1 Vol.1 1장 오브젝트와 의존관계 (추가 연관)
- 섹션 3. 스프링 IoC → 토비의 스프링 3.1 Vol.2 1장 IoC 컨테이너와 DI (추가 연관)
- 섹션 4. 스프링 AOP → 토비의 스프링 3.1 Vol.1 6장 AOP (추가 연관)
- 섹션 5. 스프링 PSA → 토비의 스프링 3.1 Vol.1 5장 서비스 추상화 (추가 연관)

> 각 섹션 파일 위쪽의 '관련 도서'에 연관성과 확인할 실습을 적어 두었습니다.
