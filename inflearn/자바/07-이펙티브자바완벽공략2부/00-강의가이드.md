| 항목 | 내용 |
|---|---|
| 분야 | Java |
| 학습 순서 | Java 분야 7번째 (필수, 전체 계획 7번) |
| 강사 | 백기선 |
| 난이도 | 중급 |

## 목적

자바 학습의 끝판왕 “이펙티브 자바”를 보다 쉽고 완벽하게 학습하세요. 이 강의를 수강하시면 여러분의 자바 프로그래밍 지식과 실력뿐 아니라 학습 능력 또한 향상시킬 수 있습니다.

## 무엇을 배우나

- 클래스와 인터페이스를 쓰기 편하고, 견고하며, 유연하게 만드는 방법
- 제네릭의 장점을 살리고 단점을 최소화하는 방법

## 이런 분께 추천

- 현업에서 자바를 사용하고 있는 모든 개발자
- 자바를 마스터 하고 싶은 개발자 또는 학생
- 이펙티브 자바를 보다 완벽하게 학습하고 싶은 개발자 또는 학생

## 선수 지식

- 자바 기초 (자바의 신, 자바의 정석, 헤드 퍼스트 자바 중 1권 필독)
- 더 자바: 자바 8
- 더 자바: 코드를 조작하는 다양한 방법
- 코딩으로 학습하는 디자인 패턴
- 이펙티브 자바 완벽 공략 1부

## 섹션 구성

1. 이펙티브 자바 완벽 공략 2
2. 아이템 15. 클래스와 멤버의 접근 권한을 최소화하라.
3. 아이템 16. public 클래스에서는 public 필드가 아닌 접근자 메서드를 사용하라.
4. 아이템 17. 변경 가능성을 최소화 하라.
5. 아이템 18. 상속보다는 컴포지션을 사용하라.
6. 아이템 19. 상속을 고려해 설계하고 문서화하라. 그러지 않았다면 상속을 금지하라.
7. 아이템 20. 추상 클래스보다 인터페이스를 우선하라.
8. 아이템 21. 인터페이스는 구현하는 쪽을 생각해 설계하라.
9. 아이템 22. 인터페이스는 타입을 정의하는 용도로만 사용하라.
10. 아이템 23. 태그 달린 클래스보다는 클래스 계층 구조를 활용하라.
11. 아이템 24. 멤버 클래스는 되도록 static으로 만들라.
12. 아이템 25. 톱 레벨 클래스는 한 파일에 하나만 담으라
13. 아이템 26. 로 타입은 사용하지 말라.
14. 아이템 27. 비검사 경고를 제거하라
15. 아이템 28. 배열보다는 리스트를 사용하라
16. 아이템 29. 이왕이면 제네릭 타입으로 만들라
17. 아이템 30. 이왕이면 제네릭 메서드로 만들라
18. 아이템 31. 한정적 와일드카드를 사용해 API 유연성을 높이라
19. 아이템 32. 제네릭과 가변인수를 함께 쓸 때는 신중하라.
20. 아이템 33. 타입 안전 이종 컨테이너를 고려하라.
