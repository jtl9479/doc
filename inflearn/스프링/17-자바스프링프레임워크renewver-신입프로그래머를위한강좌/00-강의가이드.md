# 자바 스프링 프레임워크(renew ver.) - 신입 프로그래머를 위한 강좌 강의 가이드

## 목적

신입 개발자가 스프링 프레임워크의 기본 개념부터 게시판 같은 실전 웹 개발까지 폭넓게 익힌다.

## 무엇을 배우나

개발 환경 구축과 프로젝트 생성, DI와 의존 객체 주입, 생명주기·어노테이션 설정, 웹 MVC, 세션·쿠키·리다이렉트·인터셉터, DB 연결을 다룬다.

### 인프런 소개 기준 학습 내용

- 개발 현업에서 가장 많이 쓰이는 Java Spring 프레임웍 이해
- 스프링 프레임웍 개발 기술
- 자바로 서비스 개발하기
- 게시판 만들기

## 이런 분께 추천

- Java 로 취업하고 싶은 취업 준비생
- 스프링 프레임워크를 학습해야 하는 자바 개발자
- 개발자, 프로그래머가 되고 싶은 문, 이과 대학생
- 프로그래머가 되고 싶은 분들
- 초급 자바 개발자

## 선수 지식

- JAVA 기초 문법
