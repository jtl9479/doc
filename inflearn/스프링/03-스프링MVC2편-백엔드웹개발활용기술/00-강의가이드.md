## 목적

MVC 1편의 구조 위에서 실무 웹 개발에 필요한 활용 기술을 익혀, 실제 서비스 수준의 웹 애플리케이션을 만들 수 있게 한다.

## 무엇을 배우나

타임리프, 메시지·국제화, 검증(Validation·Bean Validation), 로그인(쿠키·세션·필터·인터셉터), 예외 처리, API 예외 처리, 타입 컨버터, 파일 업로드를 배운다.

### 인프런 소개 기준 학습 내용

- 자바 백엔드 웹 기술
- 스프링 웹 기술
- 스프링 MVC

## 이런 분께 추천

- 스프링 MVC를 처음 접하는 개발자
- 개발자 취업 준비생
- 스프링 MVC를 깊이 이해하고 싶은 현업 개발자
- 스프링으로 웹 애플리케이션을 만들고 싶은 개발자

## 선수 지식

- 자바 언어
- 스프링 기본 지식
- HTTP 기본 개념
- 스프링 MVC 1편 - 백엔드 웹 개발 핵심 기술
